# Recovery deployment — 2026-10-09

Server: 143.110.223.6, Ubuntu 24.04, 2 GB RAM, Toronto.
SSH uses the owner's existing local key; no private key is stored in this project.

## Installed

- Apache + PHP 8.3 FPM, MySQL 8, Redis (Ubuntu packages).
- Application files at /var/www/viabix, including current local edits.
- Fresh viabix_db schema, 36 tables/views, built from the versioned migrations.
- No historical customer data was restored. Production starts with no users.
- A separate viabix_staging database was used for signup/login/API validation.
- Database and Redis bind to loopback. Firewall allows SSH and HTTP/HTTPS.
- Production secrets were generated on the server in a root:www-data 0640 .env.
- Internal directories, SQL, environment files and operational scripts are blocked by Apache.
- Daily root-only backups at 05:00 UTC, retained for 14 days in /var/backups/viabix.
- Initial SQL backup copied to logs/recovery-backups on the owner's computer.
